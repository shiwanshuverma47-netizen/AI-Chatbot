# MBA Buddy

A polished MBA study assistant chatbot UI with subject-based shortcuts, quick prompts, saved chat history, and a more professional assistant experience.

## ✨ Features

* 🎓 AI-powered chatbot for MBA-related queries
* 💬 Natural language conversations with contextual responses
* 📚 Guidance on MBA admissions, entrance exams, and career paths
* 🏫 Information about MBA specializations and colleges
* 📈 Career advice based on user interests
* ⚡ Fast and responsive chat interface
* 🛡️ Input validation and graceful error handling
* 📱 Clean, user-friendly, and responsive design
* 🌙 Dark/light theme toggle with local persistence
* 🧠 Quick-study prompts for fast revision sessions
* 📝 Save study notes from recent chat topics for quick revision


## 📁 Project Structure

```text
AI-chatbot/
├── index.html             # Main structure and layout
├── style.css              # Visual styling and responsive design
├── script.js              # Browser-side chat and UI logic
├── config.js              # Frontend configuration
└── README.md              # Project documentation
```

### Folder Overview

* **index.html** – Loads the page structure for the MBA Buddy assistant.
* **style.css** – Controls the visual design, responsive layout, and theming.
* **script.js** – Manages subject switching, chat replies, note saving, and UI events.
* **config.js** – Stores front-end configuration defaults.
* **README.md** – Describes the project and local development workflow.

## 🚀 Run Locally

This project is a static web app. To run it locally:

1. Open the repository in VS Code.
2. Launch a local web server from the root directory, for example:
   `python3 -m http.server 8000`
3. Visit <http://localhost:8000> in a browser.

The UI is built with vanilla HTML, CSS, and JavaScript, so no package installation is required unless you add dependencies later.
